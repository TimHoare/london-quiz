# Where's that?

A London map quiz. We name a place, you find it on a map with no labels.

Each game is ten stops that get harder as you go: three famous places, four that Londoners know, three deep cuts. Most are neighbourhoods, with a couple of landmarks, a couple of tube stations and a borough mixed in. Places you miss come back in a later game, and "What you know" maps everything you've been asked, coloured by how close you got.

```sh
npm install
npm run dev      # http://localhost:5173
npm test         # scoring, geometry, game building, data sanity checks
npm run build    # static site in dist/
```

Pushing to `main` runs the tests and deploys to GitHub Pages (`.github/workflows/deploy.yml`).

Keys: <kbd>Enter</kbd> confirms a guess or moves to the next stop, <kbd>H</kbd> shows the clue.

## Data

`public/data/` is generated by `python3 scripts/build_data.py` from the raw downloads in `data-raw/`:

| File | Source |
| --- | --- |
| `osm-places.json` | OpenStreetMap via Overpass: `place=suburb\|neighbourhood\|quarter\|town\|village` inside Greater London |
| `wikidata-sitelinks.json` | Wikidata: how many Wikipedia language editions cover each place, used to rank fame into tiers |
| `london-boroughs.geojson` | Borough boundaries from [radoi90/housequest-data](https://github.com/radoi90/housequest-data) |
| `tfl-stations.geojson` | Stations, lines and zones from [oobrien/vis](https://github.com/oobrien/vis) (tubecreature) |
| `landmarks-geocoded.json` | A hand-picked landmark list, geocoded with Nominatim and spot-checked |

The basemap is Esri World Imagery: satellite tiles, which show streets and buildings but no place names.
